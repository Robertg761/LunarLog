# LunarLog Project Description

LunarLog is a privacy-first menstrual cycle and wellness tracker for Android. The app is built to work offline, store data locally on-device, and provide advanced insights without subscriptions or data collection.

The project focuses on practical daily logging and long-term trend visibility. Users can track period days, symptoms, mood, sleep, hydration, medications, and notes, then explore trends in calendar and analysis views. LunarLog also supports local backup and restore, app lock, reminders, and generated reports for personal review or clinical discussions.

In this repository, the current Android app version is `1.10.0` (`versionCode 26`), the Room database is version 10, and the app is implemented with Kotlin, Jetpack Compose, Room, Hilt, and WorkManager.
